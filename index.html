Paste a GitHub access token that can edit the repo. It's saved only in this browser.

How do I get one?
  1. Open GitHub's new token page.
  2. Give it a name like "wishlist" and pick an expiration.
  3. Under Repository access, choose Only select repositories and pick wishlist.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it here.
